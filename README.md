# nuwa-skills

> 女娲思维蒸馏产物 — 可运行的视角 Skill 文件集合

本仓库存放由 [女娲 · Skill 造人术](https://github.com/alchaincyf/nuwa-skill) 生成的思维蒸馏产物。

每个子目录是一个独立的 Skill，可通过 WorkBuddy / Claude 等支持 SKILL.md 格式的工具加载使用。

## 已蒸馏视角

| 视角 | 类型 | 目录 | 说明 |
|------|------|------|------|
| Steve Jobs | 人物视角 | [steve-jobs-perspective](./steve-jobs-perspective/) | 苹果创始人的认知操作系统：10 个心智模型、9 条决策启发式 |
| 技术原理 | 主题视角 | [technology-principles](./technology-principles/) | 技术底层工作原理与方法论：5 个心智模型、8 条决策启发式、5 组流派分歧 |

## 使用方式

1. 将对应目录下的 `SKILL.md` 文件放入你的 Skills 目录
2. 在对话中触发关键词（如「用乔布斯的视角帮我分析」）
3. Skill 加载后将以第一人称视角响应
